# Web

Next.js App Router frontend for the Farmhouse Party Booking Platform.

Phase 2 is the design system, application shell, routing foundation, and API client. Product search, booking, and dashboards are not implemented yet.

```powershell
Copy-Item apps/web/.env.example apps/web/.env.local
cd apps/web
npm install
npm run dev
```

The site listens on `http://localhost:3000`. Internal visual review: `/design-system`.
